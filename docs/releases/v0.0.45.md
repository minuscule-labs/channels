# MinuChannels v0.0.45

Unread badges clear for the side of the split view you are reading.

## Split-view unread

- With a thread open, clicking, scrolling or typing in the parent Conversation now marks its visible latest messages read without closing the thread.
- New messages in the other pane stay unread until you use that pane.
- Opening a thread still does not mark its parent read. Closing a thread you were not reading leaves its new replies unread.
- A message must still be visible, at the end of its timeline and in a focused window to be marked read. Existing unread counts are not reset.

## Upgrade and release gates

Only the web interface changes since v0.0.44. There are no database migrations, dependency lock changes, Runtime changes or local-control protocol changes. Back up the complete stopped data directory first, and reload browser tabs after updating. Updating from v0.0.43 or earlier also brings in the [v0.0.44 changes and known limitations](v0.0.44.md).

Runtime is pinned to `08e4e41aad6e6a7b064ac25a2bebd62f5e72007c`, unchanged from v0.0.44.

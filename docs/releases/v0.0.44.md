# MinuChannels v0.0.44

Agents keep working when their skills change: after a plugin update in Codex, and after a skill is deleted or renamed in Pi.

## Codex skills

- A Codex agent that keeps every skill, when created or switched to Codex, saves no skill list. Codex uses its own current skills, so a plugin update no longer stops that agent from starting, and skills turned off in Codex stay off.
- Chosen plugin skills stay selected after a plugin update, where Codex reports which plugin a skill belongs to. Otherwise they behave as before.
- Agents and sessions already saved with a list are unchanged.

## Missing skills

- **Pi** starts and resumes without a selected skill that has been deleted or renamed. Nothing else is enabled in its place.
- **Codex and Claude Code** still refuse to start, because a skill that loads late looks the same as a missing one.
- For every harness, agent settings show saved skills that are not found and can remove them. **Session & context** lists earlier saved skills that a verified running session lacks.
- Other settings can be saved while a skill is missing or the harness is unavailable. A newly selected skill must still exist.

## Pi startup

A Pi start no longer occasionally fails because its startup file was read while half-written.

## Known limitations

- A Codex plugin skill that loads unusually late can stay on when only some skills are selected. This also affects earlier releases.
- A Codex plugin skill saved by v0.0.43 or earlier may show as not found until it is selected again. It still starts until that plugin updates.
- Selecting every skill again on an existing Codex agent saves a fixed list.
- A Codex agent with a chosen plugin skill saved by this release refuses to start if Codex stops reporting that skill's plugin, or under an earlier Channels release.

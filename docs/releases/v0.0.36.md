# MinuChannels v0.0.36

This UI-only patch removes the Skill availability text beside Send. The composer no longer displays Ready, Pending, Unavailable or Unsupported draft as a separate status indicator. The selected Skill chip and existing Send button remain.

## Unchanged behavior

Send eligibility and authenticated backend checks remain unchanged. Unsupported recipients, missing session pins, legacy sessions, retired Skills and unsupported drafts are still blocked; hiding the indicator does not make them eligible. Existing sticky/explicit recipient selection, private procedure delivery, immutable invocation receipts and uncertain-send recovery are preserved.

Conversation-wide recipient normalization and legacy-session compatibility are separate work, not part of this release. No new migration, dependency, protocol version or Runtime pin change. Runtime remains `f0ffbfcc5f24e75174bff1919aa5cd41ce22d732`; local-control protocol remains25.

## Release and upgrade

Publication requires successful PR, exact post-merge and tag CI, plus exact uploaded-artifact acceptance under [release guidance](../releasing.md). CI or source checks alone do not establish installed acceptance. Publishing does not update existing installations.

Use the normal checksum-verified updater with a complete data-directory backup and active-work protections. No agent-session replacement is needed for this display-only change; existing legacy sessions remain unchanged.

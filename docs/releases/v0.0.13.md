# MinuChannels v0.0.13

Compared with **v0.0.12**, this release brings three big improvements: **a smoother chat interface, safer agent controls, and much better visibility into what agents are doing.**

## Easier everyday chatting

- Conversations open at the newest messages and stay anchored as replies arrive, without dragging you away when you are reading older history.
- Sending keeps keyboard focus in the composer. Failed sends preserve your draft and can be retried safely.
- Basic flowcharts and sequence diagrams render inside messages, with an expanded pan-and-zoom view.
- Notifications use a clearer, louder bell and better respect whether you are actively reading the chat.
- Multiple browser tabs share their live-update connection, preventing tabs from starving status checks and agent actions.

## Cleaner navigation and participant controls

- A simpler participant sidebar with activity indicators and an optional compact avatar rail.
- Agent creation lives on the Workspace Agents page; conversation participant management selects existing agents.
- Settings and secondary controls move into menus.
- Errors are dismissible, bulk-action results can collapse, and late responses from one conversation do not disrupt another.
- `@channel` broadcasting works consistently, including fixes that prevent similarly named handles from accidentally broadcasting.

## Safer agent sessions

- **Stop** preserves the agent's session instead of destroying it.
- **Start** resumes that stopped session.
- **Reconnect** remains a separate action for an existing disconnected session.
- **New session with context** creates another session with relevant chat context.
- **Fresh session** creates another session that excludes earlier conversation messages. Agent/project instructions and later messages still apply.
- Restarting Channels or mentioning an agent cannot silently undo an intentional Stop.
- These actions do not erase public chat history or undo filesystem changes.

## Better troubleshooting

Owners and admins get:

- Failure notices beside the messages that triggered them.
- A recent operation timeline showing observed steps, failures, and uncertain outcomes.
- Diagnostics that remain accessible while an action is pending.
- Previewable, copyable reports without raw logs, prompts, credentials, or private filesystem paths.

Closing a pending-action dialog does **not** cancel the action.

## Honest session inspection

The new **Session & context** view separates:

- Recorded context policy.
- Settings verified from the running worker.
- Saved settings for future sessions.
- Saved host context limits, which can refresh when Relay reattaches without creating a new Runtime session.

Unavailable evidence says **Not verified** rather than guessing. Older workers may not provide live-profile information. Skill-command availability does not prove that instructions were loaded or used in a turn.

## Verification and known limitations

The merged implementation passed Ubuntu and macOS verification, browser regression, and release packaging/smoke CI. Local verification also covered the packaged Runtime client with temporary SQLite and deterministic fake RPC.

- One intermittent native database-related CI crash remains without a proven root cause. It did not recur in subsequent diagnostic or merged-main runs; native backtraces remain enabled. This release does not claim to fix that crash.
- The newest live-profile inspection has automated/fake-RPC coverage, but fresh genuine-Pi acceptance has not been run. Clean-account genuine-response acceptance remains outstanding under the release checklist; publishing does not claim that sign-off.
- MinuChannels remains a single-user, loopback-only local alpha for macOS and Linux. Do not expose its ports to other machines or untrusted local users.
- Image support, raw-log downloads, session branching, and automatic recovery are **not included**.

## Installing or upgrading

Download `minu-channels-0.0.13.tgz` and `SHA256SUMS` from this release and verify the checksum before installing. Back up your data before upgrading; startup applies the included private session-context migration with the product's existing migration-backup safeguards. Do not run migrations manually against an existing installation.

```bash
npm install -g ./minu-channels-0.0.13.tgz
```

Follow [installation and upgrade guidance](https://github.com/minuscule-labs/channels/blob/v0.0.13/docs/local-release.md) for safely coordinating an existing foreground or background instance. Publication itself does not upgrade or restart any installation.

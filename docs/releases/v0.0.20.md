# MinuChannels v0.0.20

Compared with **v0.0.19**, this release lets the Channels host explicitly load trusted Pi integrations while preserving disabled-by-default discovery and harness-neutral shared contracts.

## Explicit Pi integrations

Create an owner-only `pi-runtime.json` in the selected product data directory (`~/.minu/channels` by default):

```json
{
  "extensionPaths": ["/absolute/path/to/integration.ts"]
}
```

The file must be owned by the current user, use owner-only permissions (`chmod 600`), and be a regular file rather than a symlink. Reads are bounded to 64 KiB. Only `extensionPaths` is accepted: up to 100 unique absolute file/directory paths or Pi `builtin:<name>` entries. Credentials do not belong in this file.

A missing default file, `{}`, or an empty list keeps extensions disabled. Invalid/unreadable configuration stops startup rather than silently losing the requested integration. Foreground and live-review launchers support `--pi-config`; disposable review does not inherit production integrations. macOS service start/restart uses the default file in its selected data directory, not an earlier foreground override.

## Scope and lifecycle

- The list applies to all agents sharing that process's Pi adapter; it is not per-agent permissions or a filesystem/API sandbox. Extensions run trusted code, including during capability discovery, and must support headless RPC.
- Automatic extension discovery stays disabled. Enabling Pi's MCP builtin uses Pi's own enabled-server configuration, not a new server-level allowlist.
- Restart Channels to reread host configuration. Already-live workers retain their tools until replacement or suspend/resume; reconnect alone does not reload them.
- Per-agent Skills remain independent. Explicit selections are checked after extension initialization; startup/resume fails if extension packages or discovery hooks introduce unselected skills.
- Startup-hook details are retained in the bounded private Runtime log while caller-facing initialization errors remain generic.
- Integration credentials must be available to the service process. This release does not copy terminal credentials, revoke service permissions, or automatically use direct API fallback.

See [Configure Pi integrations for v0.0.20](https://github.com/minuscule-labs/channels/blob/v0.0.20/docs/local-release.md#configure-pi-integrations) for operator details.

- Runtime advances to reviewed commit `34f5b17239078d425d0df69766f159099bb848dc`, preserved in merged Runtime PR [#12](https://github.com/minuscule-labs/runtime/pull/12).
- Channels wiring is merged in PR [#54](https://github.com/minuscule-labs/channels/pull/54).

- Node.js **22.13+** is recommended; foreground use on 22.5–22.12 requires `NODE_OPTIONS=--experimental-sqlite`.

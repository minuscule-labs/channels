# MinuChannels v0.0.37

The send picker now lists only shared Workspace and Channel playbooks. Native Harness skills are no longer shown as disabled options; agents can still use their enabled native skills when requested in ordinary messages.

Picker options retain their source and revision but no longer display Ready, Pending or Unavailable. Keyboard selection and the selected Skill chip remain unchanged.

## Unchanged behavior

This is a UI-only patch. Send eligibility, authenticated backend validation, private procedure delivery, immutable revision receipts and uncertain-send recovery remain unchanged. Legacy-session compatibility and normal-message routing improvements remain separate work. Agent-scoped native slash invocation is deferred.

No migration, dependency, protocol or Runtime pin change. Runtime remains `f0ffbfcc5f24e75174bff1919aa5cd41ce22d732`; local-control protocol remains 25.

## Release and upgrade

Publication requires successful PR, exact post-merge and tag CI, plus exact uploaded-artifact acceptance under [release guidance](../releasing.md). Publishing does not update an existing installation.

Use the checksum-verified updater with a complete data-directory backup and active-work protections. No session reset is needed for this display-only update.
